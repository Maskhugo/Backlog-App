# Backlog-App

A ideia do **Backlog-App** nasceu de uma necessidade pessoal muito comum: organizar em um único lugar aquelas ótimas recomendações de filmes e séries feitas por amigos, evitando que boas indicações se percam no fundo de um chat de WhatsApp.

**A Origem**
Tudo começou de forma bem artesanal, através de uma planilha compartilhada no Google Sheets. Para enriquecer os dados, utilizávamos uma automação construída com Google Apps Script que puxava informações das obras (como sinopse, notas e pôsteres) diretamente através de uma API do IMDb. 

**O Problema**
Apesar da automação funcionar perfeitamente, a usabilidade esbarrou em um grande obstáculo: **o mobile**. Navegar, atualizar e buscar dados na planilha através da tela do celular era uma experiência frustrante e complicada.

**A Solução**
Foi assim que surgiu a ideia de desenvolver o **Backlog-App**. Ele foi criado para ser um aplicativo próprio, mantendo a essência colaborativa da planilha original (onde dados são compartilhados com usuários convidados), mas oferecendo uma interface amigável, ágil e pensada para o uso no celular.

### ✨ Principais Funcionalidades (Previstas/Atuais)
* **Organização de Recomendações:** Salve filmes e séries indicados em um só lugar.
* **Ambiente Colaborativo:** Compartilhamento de dados exclusivo com uma rede de usuários convidados.
* **Integração com IMDb:** Dados das obras preenchidos automaticamente.
* **Foco no Mobile:** Interface desenhada para ser rápida e fácil de usar na palma da mão.
